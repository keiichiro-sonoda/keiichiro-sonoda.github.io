関数の「置き場所」が速さを変える仕組みと、#33 でそれをどう止めるかを、メモリの帯を動かしながら説明します。下の番号を順に押すか、帯の上のつまみを自分で動かしてください。

熱い関数（時間の大半を使う） ほかの関数 何億回も回るループ CPU が1回に読む64バイト

図は仕組みを見せるための模型です。関数の大きさや番地は実物の値ではありません。実際の CPU では、64バイトの区切りのほかに、解読済み命令の置き場や分岐予測の表も番地の影響を受けます。数字（+0.63 秒など）は記録 #32 の門番の実測です。
